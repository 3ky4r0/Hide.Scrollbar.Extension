ScrollHide Guide

A lightweight extension to hide web page scrollbars while keeping scrolling fully functional.

How to Use

  • Toggle Globally: Click the large power button in the extension popup to turn scrollbar hiding ON or OFF.
  • Exclude Websites (Whitelist):
    • Click the + / - button in the popup to add or remove the current website.
    • Click the Sidebar button to manage all excluded domains manually.
  • Sync & Backup: Use the Export and Import buttons in the popup to backup or merge your exception list.

Tips & Troubleshooting

  • Pin the Extension: Pin the icon to your toolbar to see the status badge: ON (blue) means active, OFF (grey) means disabled/whitelisted, and no badge means restricted.
  • Page Refresh: If scrollbars do not hide or reappear immediately, try refreshing the page.
  • Canvas Scrollbars: A few websites or special PDF viewers draw their own scrollbars dynamically. These cannot be hidden by browser extensions.
Restricted Pages: By default, browser security policies restrict extensions from modifying internal pages (such as chrome://, chrome-extension://, DevTools, or the Chrome Web Store).
